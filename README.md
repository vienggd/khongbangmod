# Bike Tour at Klong Bang Mot

มินิเกมเว็บสำหรับวิชา GEN241 Beauty of Life (หัวข้อ Human Beauty)
ผู้เล่นปั่นจักรยานทัวร์ชุมชนคลองบางมด แวะทำกิจกรรมกับชาวบ้าน 2 คน:

1. **พี่ชายตกปลา**: เกมตกปลา 30 วินาที แตะในน้ำเพื่อหย่อนเบ็ด
2. **คุณน้าเจ้าของสวนส้ม**: เกมเก็บส้ม 30 วินาที มีหัวใจ 3 ดวง เก็บแค่ส้ม ห้ามเก็บมด

## โครงสร้างไฟล์

```
index.html        โครงหน้าเว็บ (ปุ่ม, กล่องบทพูด, ป๊อปอัป)
style.css         หน้าตาทั้งหมด (สี, ฟอนต์ Athiti, ปุ่ม, การ์ดป๊อปอัป)
game.js           ตัวเกมทั้งหมด
assets/game/      ภาพและเสียงที่เกมใช้ (ปรับขนาดและลบพื้นหลังแล้ว)
assets/           ภาพต้นฉบับที่วาด
```

### หาโค้ดแต่ละส่วนใน game.js

| ส่วน | ค้นหาคำนี้ |
|---|---|
| หน้าแรก / กติกา | `function showTitle`, `function showRules` |
| ฉากปั่นจักรยาน + บทพูด | `function drawRide`, `talk([` |
| เกมตกปลา | `function startFish`, `function drawFish` |
| เกมเก็บส้ม | `function startFruit`, `function drawFruit` |
| หน้าเส้นชัย | `function finale` |
| ปุ่มฟันเฟือง / หยุดเกม | `function setPause` |
| เพลงและเสียงเอฟเฟกต์ | `const music=` |
| ภาพที่ใช้ | `const SRC` |

## วิธีเปิดเกมในเครื่อง

ดับเบิลคลิก `index.html` แล้วเปิดในเบราว์เซอร์ตรง ๆ จะเปิดได้ แต่เสียงลมกับกระดิ่งจะไม่ขึ้น ให้เปิดผ่านเซิร์ฟเวอร์แบบใดแบบหนึ่งแทน

- **VS Code**: ติดตั้งส่วนขยาย *Live Server* แล้วคลิกขวาที่ `index.html` เลือก **Open with Live Server**
- **Python**: เปิด terminal ในโฟลเดอร์นี้ พิมพ์ `python -m http.server` แล้วเปิด http://localhost:8000

## เผยแพร่ด้วย GitHub Pages

ไปที่ repo บน GitHub แล้วเข้า **Settings → Pages** เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
รอประมาณ 1 นาที เกมจะออนไลน์ที่ `https://<username>.github.io/<repo>/`

## ทำงานร่วมกัน

- ก่อนเริ่มแก้ทุกครั้ง ให้ `git pull` เอาโค้ดล่าสุดลงมาก่อน
- แบ่งกันแก้คนละไฟล์หรือคนละส่วน จะได้ไม่ชนกัน
- ภาพใหม่ให้วางใน `assets/` แล้วเพิ่มชื่อไฟล์ใน `const SRC` ที่ game.js
